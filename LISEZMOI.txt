NAHOURI TECH - site web

Le site est prêt pour un hébergement statique : le logo et les visuels sont maintenant locaux dans le dossier assets/.

MISE EN LIGNE GITHUB PAGES
1. Créez un dépôt GitHub public.
2. Importez index.html, LISEZMOI.txt et le dossier assets/ à la racine.
3. Dans Settings > Pages, choisissez "Deploy from a branch", branche main et dossier / (root).
4. Enregistrez. GitHub affichera l'adresse publique du site.

MISE EN LIGNE GRATUITE
Vous pouvez aussi glisser ce dossier sur app.netlify.com/drop ou Cloudflare Pages.
